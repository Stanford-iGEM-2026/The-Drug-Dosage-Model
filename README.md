This is the drug dosing model for iGEM 2026. Given the key parameters for the diffusion through the dermis, cytosolic release of mRNA from LNP's in the cytosol, and rates of protein production and degradation, we worked together with Claude to create a fit model to predict the relative protein expression over time. This Jupyter file generates a graph for the expected protein output for three different dosage schedules; daily, every other day, and every three days.
